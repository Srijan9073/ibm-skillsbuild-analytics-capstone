# AICTE–IBM SkillsBuild Data Analytics with AI Capstone

Capstone project developed during the **6-week Virtual IBM SkillsBuild Data Analytics with AI Internship (2026)**, offered in collaboration with AICTE and BharatCares.

> **Internship ID:** IBMUEDA0483  
> **Institution:** Cooch Behar Government Engineering College (CGEC)  
> **Timeline:** August 2026 – September 2026  

---

## 📌 Project Overview
This project focuses on applying statistical techniques, exploratory data analysis, and predictive modeling (decision trees/regression) to solve real-world business challenges aligned with the UN Sustainable Development Goals (UN SDGs).

## 🛠️ Tech Stack & Methods
- **Language:** Python (Pandas, NumPy, Matplotlib, Seaborn)
- **Machine Learning:** Scikit-Learn (Supervised Learning, Regression, Classification)
- **Business Intelligence:** Power BI / Tableau
- **Curriculum:** Data Wrangling ➔ EDA ➔ Predictive Analytics ➔ AI-Driven Insights

## 📂 Deliverables
- Cleaned and transformed datasets with missing value handling.
- Exploratory analysis identifying high-impact correlations.
- Predictive model forecasting key business outcomes.
- Executive slide deck presenting insights and operational recommendations.
